# Agent icon sources

- `codex.svg` uses the OpenAI Blossom to identify Codex. The vector was sourced from
  Simple Icons 15.16.0 and is used according to the
  [OpenAI design guidelines](https://openai.com/brand/).
- `claude.svg` uses the Claude mark from
  [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/claude.svg).
- `opencode.svg` is adapted from the app favicon in the
  [OpenCode repository](https://github.com/anomalyco/opencode/blob/dev/packages/ui/src/assets/favicon/favicon.svg).

The SVGs contain no scripts, event handlers, embedded HTML, or remote asset references.
