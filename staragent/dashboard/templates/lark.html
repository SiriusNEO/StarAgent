Usage Model

private management · group-bound agents
01
Private chat manages sessions

和 StarAgent Bot 私聊只用于管理 session：/help、/sessions、/status local/dev、/history local/dev 20、/tail local/dev 120、/open local/dev。私聊不会把普通消息发给 agent。

02
Agent chat lives in a Feishu group

每个 agent session 对应一个飞书对话群。在群设置的“群机器人 / 添加机器人”里添加 StarAgent，然后发送 /use local/my-session 绑定这个群。

03
Talk inside the bound group

绑定后，同一个群里的普通消息会发到对应 agent session。群里命令默认使用当前绑定：/status、/history 20、/tail 120、/open。

04
Inspect output on demand

需要看终端细节时，在绑定群里用 /tail 120 主动拉取最近输出，或用 /open 打开 Dashboard terminal。没有结构化 transcript 时，/history 会提示改用 /tail。

05
Command quick reference

私聊：/sessions、/status local/dev、/history local/dev 20。群聊：/use local/dev 绑定，之后直接发消息，或用 /status、/history 20、/tail 120、/open。

Feishu Setup

app · events · permissions · allowlist
01
Create an internal app

飞书开放平台里创建“企业自建应用”。在“凭证与基础信息”复制 App ID 和 App Secret，填到上面的表单。

02
Enable the bot

在“应用能力”里启用机器人，设置名称和头像。私聊用于 session 管理；agent 对话需要把机器人从群设置里的“群机器人 / 添加机器人”入口加入对应对话群。

03
Subscribe to message events

在“事件与回调”里启用事件订阅，使用 WebSocket/长连接模式，订阅 im.message.receive_v1。

04
Grant permissions and publish

添加消息接收、机器人发消息、发送和删除消息表情回复权限，发布应用版本并完成企业管理员审批。

{{ lark.commands.scopes }}
05
Lock down access

第一次联调可以临时勾选 Allow all。私聊里发送 /sessions；对话群里发送 @StarAgent /use local/dev。Worker Output 会打印 open_id、chat_id、root_id、thread_id，复制可信用户或群聊到 allowlist 后关闭 Allow all。
